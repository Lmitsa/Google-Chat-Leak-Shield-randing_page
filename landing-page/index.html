퀵 테스트 프리셋

평가용 테스트 문장을 클릭하여 즉시 입력창에 복사하고 Leak Shield의 경고 알림 동작을 확인할 수 있습니다.

Chrome Extension 간편 설치 가이드

제출된 프로젝트 패키지를 다운로드 받아 구글 크롬 브라우저에 4단계의 짧은 클릭만으로 설치하여 Google Chat 상에서 완벽히 연동시킬 수 있습니다.

1

배포 패키지 다운로드

페이지 최상단 또는 하단의 '패키지 zip 파일 다운로드' 버튼을 클릭하여 leak-shield-extension.zip 파일을 다운로드합니다.

2

압축 해제 및 폴더 이동

다운로드 받은 zip 파일의 압축을 해제합니다. 해제 결과물로 생성되는 폴더 안에 manifest.json 등의 파일이 정상적으로 포함되어 있는지 확인합니다.

3

Chrome 개발자 모드 활성화

크롬 브라우저 주소창에 chrome://extensions를 입력하여 이동한 뒤, 우측 상단에 위치한 '개발자 모드(Developer mode)' 토글 스위치를 켭니다.

4

압축해제된 확장 프로그램 로드

좌측 상단의 '압축해제된 확장 프로그램을 로드(Load unpacked)' 버튼을 클릭하고, 2단계에서 압축을 해제했던 익스텐션 폴더를 통째로 선택하여 로드하면 설치가 완료됩니다!

5

Google Gemini API 키 발급

Google AI Studio에 접속하여 'Create API key' 버튼을 눌러 새로운 Gemini API 키를 발급받습니다.

6

확장 프로그램 옵션

Google Chat Leak Shield를 찾습니다. 세부정보 버튼을 누른 후, 스크롤하여 확장 프로그램 옵션을 누릅니다.

7

API 키 연동 및 적용

'Enterprise API Configuration' 항목에 발급받은 API 키를 입력하고 'Apply Configuration'을 클릭하면 모든 준비가 완료됩니다.
